Лабораторная работа по дисциплине "Компьютерная графика" №0



Программа реализует отображение вращающегося пропеллера в консоли, где предусмотрена возможность паузы и изменения скорости вращения.



!\[Демонстрация](<LR0/gif/demo.gif>)



Описание задачи

Необходимо разработать программу, которая в центре экрана один символ по очереди меняет по циклу | / - \\ с заданным интервалом, создавая вращение. Space - пауза, +/- интервал, q выход. Требуется выводить символ без мерцания и корректно восстанавливать состояние вращения при любом способе выхода.

&#x20;

Программа реализована на языке:

Язык	Интерпретатор/Версия	Среда разработки

Python	Python / 3.11.5		PyCharm 2023 2.1



Используемые библиотеки:

os - получение размера консоли

sys - управление потоком вывода

time - таймер анимации и задержка цикла

ctypes - вызов Windows API для включения ANSI-последовательностей

msvcrt - неблокирующее чтение клавиатуры



Описание возможностей:

Программа позволяет визуализировать вращение пропеллера в центре консоли без мерцания — перерисовываются только две позиции экрана (строка статуса и центр), а не весь экран целиком.



Управление:



Клавиша	Действие

Space	Пауза / продолжить вращение с того же кадра

\+ или =	Увеличить интервал (медленнее)

\- или \_	Уменьшить интервал (быстрее)

q / Q / й / Й	Выход

Esc	Выход (работает в любой раскладке)

Ctrl+C	Аварийный выход с корректным восстановлением консоли

Диапазон интервала: 0.05 … 2.0 с.
